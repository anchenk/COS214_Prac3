\doxysubsection{Detailed Description}
Demonstration program for The Heap \& Heap Artisanal Bazaar. 

This program demonstrates\+:
\begin{DoxyItemize}
\item Composite pattern\+: Building an event tree with multiple levels
\item \doxylink{classObserver}{Observer} pattern\+: Broadcasting notices and cascading notifications
\item Original features\+: Shift changes, medical alerts, multi-\/language support
\item Runtime reorganisation\+: Transferring vendors between areas
\end{DoxyItemize}
