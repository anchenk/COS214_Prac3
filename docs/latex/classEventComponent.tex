\doxysubsection{Detailed Description}
Abstract Component participant in the Composite pattern. 

Represents any element in the event structure -\/ both composites (\doxylink{classEventGroup}{Event\+Group}) and leaves (\doxylink{classEventUnit}{Event\+Unit}). Defines the common interface for all components.

This class also implements \doxylink{classObserver}{Observer}, allowing components to receive notifications from Subjects.

\begin{DoxyNote}{Note}
This class is abstract and cannot be instantiated directly. 

Implements the Component role in the Composite pattern. 

Implements the \doxylink{classObserver}{Observer} role in the \doxylink{classObserver}{Observer} pattern. 
\end{DoxyNote}
