Detailed Description

Concrete Leaf - Performance stage for live entertainment.

Represents a stage where performances are held. Reacts to weather alerts by pausing performances, schedule changes, and medical alerts.

◆ handleNotice()

void PerformanceStage::handleNotice ( Notice *  notice)
overridevirtual

Handle a received notice from the Subject.

Reacts to different notice types:

  • Open: Opens the stage
  • Close: Pauses performance and closes stage
  • WeatherAlert: Pauses performance
  • Evacuate: Pauses performance and closes
  • ScheduleChange: Changes stage manager (if "new_manager" detail exists)
  • MedicalAlert: Pauses performance
