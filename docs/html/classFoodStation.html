Detailed Description

Concrete Leaf - Food preparation and tasting station.

Represents a food station in the bazaar that serves prepared food. Reacts to weather alerts, evacuation, and shift changes.

void FoodStation::handleNotice ( Notice *  notice)
overridevirtual

Handle a received notice from the Subject.

Reacts to different notice types:

  • Open: Opens the station
  • Close: Closes the station
  • WeatherAlert: Remains open
  • Evacuate: Closes station
  • ScheduleChange: Changes chef (if "new_chef" detail exists)
  • MedicalAlert: Closes station (if serving)
